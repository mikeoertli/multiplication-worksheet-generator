# Multiplication Worksheet Generator

This is a simple utility to generate multiplication practice test worksheets. The idea is that kids are timed and must
complete all questions within 2 minutes.

The generated worksheets will have 25 questions. Each number between 0 and 12 multiplied by the target number, including
the reverse (i.e. 1 × 5 and 5 × 1), since the number times itself has no unique inverse, we end up with 25 total questions.
